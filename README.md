
# GESTION — Application de gestion des étudiants

## Présentation

GESTION est une application web permettant de gérer les informations des étudiants à l'aide de PHP, MySQL et MySQLi.

## Technologies utilisées

- HTML5 : structure des pages.
- CSS3 : mise en forme de l'interface.
- PHP : traitement des données.
- MySQL : stockage des informations.
- MySQLi : communication entre PHP et MySQL.

## Fonctionnalités

- Ajouter un étudiant.
- Afficher la liste des étudiants.
- Modifier les informations d'un étudiant.
- Supprimer un étudiant.

## Organisation des fichiers

- `index.html` : page d'accueil.
- `style.css` : feuille de style.
- `formulaire.html` : formulaire d'ajout.
- `formulaire2.html` : formulaire de suppression.
- `formulaire4.html` : formulaire de modification.
- `create.php` : ajout d'un étudiant.
- `select.php` : affichage des étudiants.
- `update.php` : modification d'un étudiant.
- `delete.php` : suppression d'un étudiant.
- `connexion.example.php` : exemple de configuration de connexion.

## Installation

1. Installer un environnement local comme XAMPP.
2. Démarrer Apache et MySQL.
3. Créer la base de données `gestion_etudiant`.
4. Importer le fichier `gestion_etudiant.sql` dans phpMyAdmin.
5. Copier `connexion.example.php` sous le nom `connexion.php`.
6. Adapter les paramètres de connexion à son environnement.
7. Placer le projet dans le dossier `htdocs`.
8. Ouvrir le navigateur et accéder à :

   http://localhost/GESTION/
